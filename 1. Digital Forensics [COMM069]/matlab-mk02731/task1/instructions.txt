Use LSB_steg_embed to hide the plaintext "Hello World" (without the quotes)
in the cover image provided by the image.png file.

The embedding must be a sequential path embedding and the plaintext must not
be encrypted.

Compute the SHA-256 crypto_hash of the resulting stego image. Convert the
hash into a hexadecimal string with the command dec2hex and assign it to
the variable h. Then the command   h(:)'
(including the apostrophe, which is the transpose operator) will give you
a hexadecimal string that will decrypt the file code.7z

Use the discovered code to unlock the next task.
